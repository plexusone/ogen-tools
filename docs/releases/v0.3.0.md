# v0.3.0

**Release Date:** 2026-06-20

## Highlights

Three new tools to extend ogen compatibility:

- **ogen-fixformdata**: Fix form-data encoding of empty JSON arrays/objects
- **ogen-fixbinary**: Fix nullable binary file fields in multipart forms
- **ogen-fixnull31**: Preprocess OpenAPI 3.1 nullable type arrays for ogen

## Added

### ogen-fixformdata

CLI tool to fix form-data encoding in `oas_request_encoders_gen.go`. Prevents API 400 errors caused by ogen sending empty strings for nil array/object fields in multipart form requests.

**The Problem:**

When ogen generates form-data request encoders, it unconditionally encodes JSON fields even when they're nil:

```go
// Before: Always sends empty string for nil fields
}(&enc)
return e.EncodeValue(string(enc.Bytes()))
```

This causes APIs to reject requests with errors like "Invalid additional format options" when optional array fields are nil.

**The Fix:**

`ogen-fixformdata` adds a length check to skip encoding empty content:

```go
// After: Only sends content when present
}(&enc)
if len(enc.Bytes()) > 0 {
    return e.EncodeValue(string(enc.Bytes()))
}
return nil
```

### ogen-fixbinary

CLI tool to fix nullable binary file fields in `oas_schemas_gen.go` and `oas_request_encoders_gen.go`.

**The Problem:**

When an OpenAPI spec has a binary field with `nullable: true`, ogen generates `OptNilString` instead of `OptMultipartFile`, causing file uploads to be encoded as string form fields rather than proper multipart file attachments.

**The Fix:**

`ogen-fixbinary` transforms the generated code:

1. Changes `File OptNilString` to `File OptMultipartFile` in multipart struct definitions
2. Replaces string-based form encoding with proper `WriteMultipart` file encoding

### ogen-fixnull31

CLI tool to preprocess OpenAPI 3.1 specs before running ogen. Addresses [ogen#880](https://github.com/ogen-go/ogen/issues/880).

**The Problem:**

ogen cannot parse OpenAPI 3.1 specs that use the nullable type array syntax:

```yaml
properties:
  comments:
    type:
      - string
      - "null"
```

This fails with: `cannot unmarshal !!seq into string`

**The Fix:**

`ogen-fixnull31` preprocesses the spec to convert to OpenAPI 3.0 format:

```yaml
properties:
  comments:
    type: string
    nullable: true
```

It also downgrades `openapi: 3.1.x` to `openapi: 3.0.3`.

## Installation

```bash
go install github.com/plexusone/ogen-tools/cmd/ogen-fixformdata@v0.3.0
go install github.com/plexusone/ogen-tools/cmd/ogen-fixbinary@v0.3.0
go install github.com/plexusone/ogen-tools/cmd/ogen-fixnull31@v0.3.0
```

## Usage

```bash
# Preprocess OpenAPI 3.1 spec (if needed)
ogen-fixnull31 openapi.yaml -o openapi-ogen.yaml

# Generate API code with ogen
ogen --package api --target internal/api --clean openapi-ogen.yaml

# Apply post-processing fixes
ogen-fixnull internal/api/oas_json_gen.go
ogen-fixerror internal/api/oas_response_decoders_gen.go
ogen-fixformdata internal/api/oas_request_encoders_gen.go
ogen-fixbinary internal/api/oas_schemas_gen.go internal/api/oas_request_encoders_gen.go

# Verify build
go build ./...
```

## Example generate.sh

```bash
#!/bin/bash
set -e

# Preprocess OpenAPI 3.1 spec (if needed)
go run github.com/plexusone/ogen-tools/cmd/ogen-fixnull31@latest openapi.yaml -o openapi-ogen.yaml

# Generate API code
ogen --package api --target internal/api --clean openapi-ogen.yaml

# Post-process: Fix ogen bugs
go run github.com/plexusone/ogen-tools/cmd/ogen-fixnull@latest internal/api/oas_json_gen.go
go run github.com/plexusone/ogen-tools/cmd/ogen-fixerror@latest internal/api/oas_response_decoders_gen.go
go run github.com/plexusone/ogen-tools/cmd/ogen-fixformdata@latest internal/api/oas_request_encoders_gen.go
go run github.com/plexusone/ogen-tools/cmd/ogen-fixbinary@latest internal/api/oas_schemas_gen.go internal/api/oas_request_encoders_gen.go

# Verify
go build ./...
```
