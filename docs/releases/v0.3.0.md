# v0.3.0

**Release Date:** 2026-06-15

## Highlights

New `ogen-fixformdata` tool to fix form-data encoding of empty JSON arrays/objects.

## Added

- **ogen-fixformdata**: CLI tool to fix form-data encoding in `oas_request_encoders_gen.go`. Prevents API 400 errors caused by ogen sending empty strings for nil array/object fields in multipart form requests.

## The Problem

When ogen generates form-data request encoders, it unconditionally encodes JSON fields even when they're nil:

```go
// Before: Always sends empty string for nil fields
}(&enc)
return e.EncodeValue(string(enc.Bytes()))
```

This causes APIs to reject requests with errors like "Invalid additional format options" when optional array fields are nil.

## The Fix

`ogen-fixformdata` adds a length check to skip encoding empty content:

```go
// After: Only sends content when present
}(&enc)
if len(enc.Bytes()) > 0 {
    return e.EncodeValue(string(enc.Bytes()))
}
return nil
```

## Installation

```bash
go install github.com/plexusone/ogen-tools/cmd/ogen-fixformdata@v0.3.0
```

## Usage

```bash
# Generate API code with ogen
ogen --package api --target internal/api --clean openapi.json

# Apply post-processing fixes
ogen-fixnull internal/api/oas_json_gen.go
ogen-fixerror internal/api/oas_response_decoders_gen.go
ogen-fixformdata internal/api/oas_request_encoders_gen.go

# Verify build
go build ./...
```

## Example generate.sh

```bash
#!/bin/bash
set -e

go run github.com/plexusone/ogen-tools/cmd/ogen-fixerror@latest internal/api/oas_response_decoders_gen.go
go run github.com/plexusone/ogen-tools/cmd/ogen-fixformdata@latest internal/api/oas_request_encoders_gen.go

# Verify
go build ./...
```
