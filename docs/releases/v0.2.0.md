# v0.2.0

**Release Date:** 2026-02-28

## Highlights

Organization rename from agentplexus to plexusone.

## Breaking Changes

- **Module path changed** from `github.com/agentplexus/ogen-tools` to `github.com/plexusone/ogen-tools`

Update your imports:

```go
// Before
import "github.com/agentplexus/ogen-tools/ogenerror"

// After
import "github.com/plexusone/ogen-tools/ogenerror"
```

Update your install commands:

```bash
# Before
go install github.com/agentplexus/ogen-tools/cmd/ogen-fixnull@latest

# After
go install github.com/plexusone/ogen-tools/cmd/ogen-fixnull@latest
```

## Fixed

- Use `#nosec` directive for gosec G703 suppressions in CLI tools

## Dependencies

- Bump `github.com/ogen-go/ogen` from 1.18.0 to 1.20.0

## Migration

1. Update all import paths from `github.com/agentplexus/ogen-tools` to `github.com/plexusone/ogen-tools`
2. Update your `generate.sh` or build scripts to use the new module path
3. Run `go mod tidy` to update dependencies
